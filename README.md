# Week 4: JavaScript Fundamentals 🧠

An interactive development project showcasing JavaScript foundational implementations, control structures, and array-of-objects data transformation pipelines.

## 📋 Project Deliverables & Architecture

- **`index.html`**: Host page containing the production runtime script hook.
- **`main.js`**: Core application runtime engine processing variables, math operations, and functional mini-projects.
- **`.gitignore`**: Environment filter preventing tracking of system metadata.

---

## 🛠️ Completed Assignments & Core Features

### 1. Variables & Diagnostic Math Operational Metrics (Tasks 7.1 & 7.2)
- Created scoped configurations using strict variable constraints (`let` and `const`).
- Calculated dynamic programmatic thresholds including absolute age conversion values down to specific hour metrics and structural century milestones.

### 2. Functional Programmatic Implementations (Task 7.3)
- Constructed complex logic for geometric layout computation engines (`calculateArea`).
- Programmed multi-step temperature conversion algorithms (`celsiusToFahrenheit`).
- Engineered advanced parsing methods to automatically split and map strings into dynamic typographic initials (`getInitials`).

### 3. Interactive Console Calculator Mini-Project
- Built an expandable switch-case math router (`calculate`) supporting:
  - Addition (`+`) & Subtraction (`-`)
  - Multiplication (`*`) & Division (`/`)
  - Modulus remainder mapping (`%`)
  - Multi-factor exponentiation (`**`)
- Implemented explicit safety guardrails to evaluate and prevent division-by-zero fatal exceptions.

### 4. Student Grade Tracker & Report Card Engine Mini-Project
- Built a data tracking matrix utilizing multi-layered object properties to store student data records.
- Implemented data transformation arrays to process complex operations:
  - Calculated targeted individual and group averages across unique subject fields using `.reduce()`.
  - Filtered student objects to automatically isolate struggling records beneath explicit academic benchmarks.
  - Constructed a report generator that automatically maps numeric scores directly into corresponding letter grades (`A` through `F`).

## 🚀 How to Run & Verify the Project

1. Clone this repository locally using Git Bash.
2. Open the directory and launch `index.html` via **Live Server**.
3. Press **F12** (or right-click and choose **Inspect**) to view the clean, formatted script execution inside the **Console** tab.
